# Frontend 畫面微調紀錄

更新日期：2026-09-12

## 範圍

本文件只記錄既有畫面的輕量調整，不包含大 scope、新功能、API 契約或商業邏輯變更。

## 首頁

### 當天路線圖

- 原本直接顯示的當天路線圖改為方塊入口，方塊內只保留地圖 icon 與「本日路線」。
- 點擊方塊後，以 modal 顯示當天路線圖。
- 整個方塊皆可點擊，並使用 button 語意；不能只有 icon 或文字可觸發。
- Modal 需有明確的關閉按鈕，並支援 Escape／返回鍵；開啟時將焦點移入 modal，關閉後將焦點還給「本日路線」入口。
- 此項包含 modal 開關與 focus 管理，屬於小型互動調整，不是純 CSS 樣式修改。

### 行程項目

- 將每個項目的「在 Google Maps 查看」文字連結改為地圖 icon。
  - 保留可辨識的無障礙名稱，例如 `aria-label="在 Google Maps 查看"`，不能只靠 icon 傳達用途。
  - 維持外部連結行為與既有 Google Maps URL，不改導航邏輯。
- 當天已過時間的行程預設收合。
  - 收合後仍需看得出有幾筆較早行程，並提供展開方式。
  - 展開後使用白色內容底，與灰藍 header 明確區隔；已過行程可以弱化，但文字對比不能接近 disabled 狀態。
  - 此項涉及「目前時間」判斷與預設展開狀態；若現有畫面尚無相應資料或收合機制，應另列為互動邏輯，不納入純樣式調整。
- 當前節點增加簡單提示動畫：在橘色圓圈外圍顯示循環放大的線圈。
  - 動畫只用於當前節點，避免多個節點同時干擾閱讀。
  - 遵守 `prefers-reduced-motion`；使用者偏好減少動態效果時停止循環動畫，但仍保留靜態的當前狀態標示。
- 保留首頁當前節點的橘圈，不可因 mock 行程時間尚未開始而移除這個樣式。
  - 目前只有行程日期與行程時區的今天相同，且當下時間落在活動時段內，才會顯示「現在」與橘色動態圈；mock 全是未來時間時沒有當前節點屬於預期結果。
  - 沒有正在進行的活動時，下一個活動要顯示橘色動態圈提醒，並保留「接下來」文字，不能只靠顏色表達狀態。
  - 有正在進行的活動時，只有「現在」使用橘色實心節點與循環放大效果；「接下來」維持原本的綠圈。
  - 只要節點使用橘圈，就必須播放相同的外圈動畫。

### 預約／不可移動狀態文案

- 移除「不可隨意移動」；這句帶有責備語氣，也沒有清楚交代限制原因。
- 若狀態代表 `booking=true`，改顯示中性的「已預約」。
- 若只有 `movable=false`，不能直接等同「已預約」；需先確認實際原因，再決定使用「行程固定」或更具體的限制文案。
- 不建議完全隱藏限制狀態。已預約或不可移動會影響重排與方案套用，至少要保留簡短文字，不能只用鎖頭 icon 或顏色表示。

## 比較行程頁

### 方案展開區塊

- 點擊「查看行程」後，展開的「方案中的行程」區塊需要提高與方案卡片背景的視覺對比。
- 使用較明確的背景色、邊框或區塊標題層級區隔展開內容，但沿用現有配色，不建立新的 design token。
- 「方案中的行程」外層使用暖橘底，日期 header 使用綠色底，活動內容維持白底；不可再用相近的淡藍灰堆疊三個層級。
- 展開狀態的按鈕也要有可辨識的 selected／expanded 樣式，讓使用者看得出目前正在查看哪個方案。
- 不只靠淡色背景表示展開狀態；保留「方案中的行程」標題及按鈕的「收起行程」文案。

### 活動時間長度

- 首頁與比較行程頁的活動時間長度統一改為「X 小時 X 分」格式，不直接顯示累計分鐘數。
  - `90` 分鐘顯示為「1 小時 30 分」。
  - 不足一小時顯示為「45 分」。
  - 整點時數省略零分鐘，例如 `120` 分鐘顯示為「2 小時」。
- API 的 `duration_minutes` 契約維持不變，只在前端格式化顯示；此項屬於 presentation logic，不是 API 或商業邏輯變更。

## 等待頁

### 等待時閱讀

- 將現有的轉乘提醒替換為較有趣的淺草寺籤詩知識。
- 標題：「淺草寺的凶籤特別多？」
- 內文：「淺草寺沿用古老的『觀音百籤』比例，凶籤約占三成。不是刻意增加，而是一直沒有調低比例。」
- 標題與內文需有清楚的字級／字重層級，不要把整段內容塞在同一個 paragraph。
- 事實依據可參考[淺草寺受訪說明](https://chanto.jp.net/articles/-/1001981?display=b)；不要延伸寫成「所有或多數神社都降低凶籤比例」。

## Accordion

- 將既有 accordion 箭頭替換為 Lucide 的 [`ChevronDown`](https://lucide.dev/icons/chevron-down)。
- 展開時旋轉 icon 表示狀態，動畫保持簡短，並遵守 `prefers-reduced-motion`。
- Icon 僅作為視覺提示；accordion button 仍需保留 `aria-expanded`，不能只靠箭頭方向傳達展開狀態。

## 驗收重點

- 375px 與 414px 寬度下沒有水平溢出。
- icon 點擊區域至少為 44×44px，鍵盤 focus 清楚可見。
- 「本日路線」方塊可用觸控與鍵盤開啟 modal，modal 可正常關閉且焦點移動正確。
- 已過行程可重新展開，且不會收合當前或未來行程。
- 當前節點除了動畫外，仍有靜態視覺差異；沒有當前節點時，下一個活動會顯示橘色動態圈與「接下來」；有當前節點時，接下來的活動維持綠圈。
- 預約與不可移動限制以中性、明確的文字呈現。
- 比較頁展開的方案行程與外層卡片有清楚層級，展開按鈕狀態可辨識。
- 所有活動時間長度使用一致格式，且不出現「0 小時」或「0 分」。
- Accordion 的展開狀態與箭頭方向一致，且不只靠 icon 傳達狀態。
